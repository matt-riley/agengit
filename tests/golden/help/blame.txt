USAGE:
    agit blame [OPTIONS] <FILE>

DESCRIPTION:
    Show per-line step attribution for a file path.

OPTIONS:
    --no-limits
        Disable the blame file-size cap for this invocation when blame output is available.
    -h, --help
        Display this help and exit.

EXAMPLES:
    # show blame for a file
    agit blame src/main.zig

NOTES:
    Blame recording is not yet available. When blame rendering lands, AGIT_MAX_FILE_BYTES will set the default large-file cap and --no-limits will disable it for one run.
