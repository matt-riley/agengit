USAGE:
    agit observe [OPTIONS] <SOURCE>

DESCRIPTION:
    Run an experimental observer source and record newly seen events.

OPTIONS:
    --json
        Render observe results as structured JSON.
    --once
        Process one batch of available events and exit.
    --input <PATH>
        Source-specific input path (required for jsonl).
    -h, --help
        Display this help and exit.

EXAMPLES:
    # process a JSONL observer file once
    agit observe --once jsonl --input observer.jsonl
    # emit machine-readable observe stats
    agit observe --json --once jsonl --input observer.jsonl

NOTES:
    Observer sources are explicit and experimental. Current sources run one pass and persist watermarks under .agit/observers/ for duplicate suppression on rerun.
