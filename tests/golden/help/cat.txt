USAGE:
    agit cat [OPTIONS] <HASH>

DESCRIPTION:
    Print a raw object by its BLAKE3 hash.

OPTIONS:
    --redacted
        Redact obvious secrets in the rendered object output.
    --full
        Render full object output even when redaction is the repo default.
    -h, --help
        Display this help and exit.

EXAMPLES:
    # print object content
    agit cat abc123def
