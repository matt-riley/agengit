agit - AI agent version control

Usage: agit [options] <command> [command-options]

Options:
  -h, --help     Display this help and exit.
  -V, --version  Print version and exit.

Commands:
  init          Set up agit in the current repository
  observe       Run an experimental observer source
  uninstall     Remove agit hooks from agent configurations
  doctor        Check agent hook configurations and store health
  fsck          Verify store integrity without mutating data
  gc            Prune unreachable store data and stale temporaries
  push          Upload store history to a configured remote
  pull          Download store history from a configured remote
  export        Write a portable bundle from selected sessions
  import        Import a portable bundle into the local store
  status        Show the investigation dashboard
  timeline      Show recent recorded steps
  sessions      List recorded agent sessions
  log           Show step history for a session
  restore       Restore files from a recorded snapshot
  show          Show details of a step
  diff          Show a text diff for a step
  between       Show steps recorded between Git revisions
  grep          Search recorded messages and tool activity
  blame         Show per-line step attribution for a file
  cat           Print a raw object by hash
  privacy       Scan reachable content for sensitive data
  reindex       Rebuild the index from the object store
  version       Print version information
  completion    Generate shell completion scripts

Run 'agit <command> --help' for command-specific help.
