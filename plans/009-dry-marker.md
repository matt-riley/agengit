## Why this matters

The string `"Generated by 'agit init'"` is used as a marker to identify
agit-generated JS extension files (for pi and copilot). It appears in four
places across three files:
- `src/cli/pi_extension.zig:20` (the template body that produces the marker)
- `src/cli/uninstall.zig:54` (detecting agit extensions to know which files to
  delete)
- `src/cli/doctor.zig:833` (doctor check for agent config state)
- `src/cli/doctor.zig:1079` (doctor JSON output check)

Each is a separate string literal with a comment saying "keep in sync." If
someone changes the marker in `pi_extension.zig` without updating the other two
modules, uninstall silently leaves stale extension files and doctor reports
false negatives. This is a synchronization hazard with low effort to fix.

## Steps

### Step 1: Export the marker from `pi_extension.zig`

Add a public constant to `src/cli/pi_extension.zig` at the top of the file
(after imports, before the `body` const):

```zig

/// Shared by `uninstall.zig` and `doctor.zig` to detect agit-generated
/// extensions.
pub const js_extension_marker = "Generated by `agit init`";
```

The existing `body` const already contains this string as part of its literal
text — it is embedded within the JS comment on line 1 of the template. No change
is needed to `body` or `render`.

**Verify**: `zig build test` → all tests pass. Specifically:
- `test "render embeds the agit binary as a JSON literal"` must still pass
