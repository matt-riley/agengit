## Findings considered and rejected

- **AES-256-GCM per-object nonce derivation from the content hash**
  (`src/store/remote.zig:1038`) — not a finding. ADR 023 already documents
  this exact tradeoff explicitly ("hides object contents, not equality of
  objects... a per-deployment random salt cannot be stored without breaking
  dedup"). Since objects are content-addressed, identical hash implies
  identical plaintext, so nonce reuse only ever pairs with identical
  plaintext — it does not enable the AES-GCM "forbidden attack" (key
  recovery via nonce reuse across *different* plaintexts). Settled by ADR,
  not a bug.
- **"No CI enforcement of README docgen freshness"** — false on inspection.
  `build.zig` already wires `check-docgen` (running `docgen --check`) into
  the `check` step (`build.zig:219-222,255`), so drift is already caught by
  `zig build check`.
- **"Copilot/Pi hook-extension installation has no e2e coverage"** — false
  on inspection. `tests/e2e/init/fresh.zig` already creates fake Copilot and
  Pi agents, runs `agit init`, and asserts both `.mjs` and `.js` extensions
  are written with the expected hook names; `tests/e2e/uninstall/clean.zig`
  covers the corresponding cleanup path.
- **"`store.zig`/`snapshot.zig`/`integrity.zig` have zero unit tests"** —
  false on inspection. `grep -c '^test "' ` shows 14, 12, and 5 embedded
  tests respectively. `bundle.zig` (1 test) was the real gap in that
  category — addressed by plan 005.
- **S3 endpoint DNS-rebinding / localhost-check bypass**
  (`src/store/remote.zig:563`) — plausible in theory but low real-world
  exploitability for a local dev CLI talking to an operator-configured S3
  endpoint; not selected for a plan this round. Worth a second look if
  `agit push`/`pull` is ever pointed at untrusted/dynamic endpoints by
  default.
- **`agit grep` content search doesn't pre-filter via the FTS5
  `search_entries` index before scanning blobs** (perf) — plausible
  optimization but needs a schema/freshness check before committing to an
  approach; not selected for a plan this round.
