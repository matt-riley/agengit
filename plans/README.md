## Findings considered and rejected

- **Cross-filesystem temp file writes in atomic_json.zig**: The temp path includes an absolute directory prefix matching the target, so the file lands on the same filesystem. Not a real issue.
- **Path traversal from hook payload cwd**: Zig's `openDir` uses `openat` which does not resolve `..` components. The worst-case is recording in the wrong repository, which self-corrects.
- **Lock path buffer overflow in event.zig**: The session key is always exactly 64 hex chars; 96-byte buffers are safe.
- **Recall FTS index missing**: FTS5 index (`search_entries`) already exists via migration 6 and is used by both `agit grep` and `agit recall`.
- **Privacy scan dedup by rule name**: Each `appendTextFindings` call creates a fresh HashMap; findings from different sources are counted independently. Not a bug.
- **Backup overwrite on --force re-runs**: The `.agit.bak` backup is a convenience; users can recover configs via git.
